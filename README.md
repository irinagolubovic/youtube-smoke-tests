# YouTube Smoke Tests

This project is a UI and API test automation suite for the YouTube web application, built with Playwright and TypeScript. 
It follows the Page Object Model (POM) design pattern and focuses on validating the application's core functionality through smoke testing.

## Technologies

Playwright, TypeScript, Node.js and GitHub Actions.

## Covered Scenarios

- Homepage Loading & Search
- Navigation
- Video Playback
- Sign In Page Accessibility
